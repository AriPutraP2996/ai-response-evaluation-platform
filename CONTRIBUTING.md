# Contributing

Thanks for your interest in improving this project.

## Development

1. Create a branch for your change.
2. Install dependencies with `python -m pip install -r requirements.txt`.
3. Run `python -m pytest -q`.
4. Run `python run_evaluation.py`.
5. Keep changes focused and documented.
6. Open a pull request with a clear description of the change.

## Scope

Contributions should preserve the project's core principles: deterministic behavior, transparent scoring, reproducibility, and honest documentation of limitations.
